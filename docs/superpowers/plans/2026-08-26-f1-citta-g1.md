# La città esiste (blocco G, fase G1) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Una pista può dichiararsi cittadina, e allora attorno a lei non c'è più il verde: un muro continuo di facciate chiude la vista appena oltre le barriere, il prato diventa asfalto e marciapiede, colline e boschi si spengono. Provabile su una pista di prova generata da script.

**Architecture:** La facciata **non** è una fila di modelli: è un nastro estruso lungo il tracciato, come già lo sono asfalto, cordoli, ghiaia e barriere. Segue le curve per costruzione invece di adattarsi, e vive in poche mesh invece che in centinaia di oggetti — che conta, perché questo gioco è GPU-bound sui pixel e un muro che chiude la vista è esattamente ciò che riempie lo schermo. I «palazzi diversi» nascono come variazione di altezza e colore lungo il nastro, con le finestre come motivo ripetuto in vertex color: la stessa tecnica dei cordoli a scacchi e del prato dipinto.

**Tech Stack:** Node.js, `node --test` + `node:assert/strict`, moduli UMD condivisi (`frontend/shared/*.js`), Three.js r128 lato client.

**Spec:** `docs/superpowers/specs/2026-08-26-f1-ambientazione-cittadina-design.md`

### Task 2: Il profilo della città: dove sta la facciata e quanto è alta

Il cuore geometrico, e **senza Three.js**: un modulo puro che, campione per campione, dice a che distanza dall'asse comincia la facciata, quanto è alta e di che colore è. La mesh la costruirà il Task 3 leggendo questo.

Dividere qui non è burocrazia: è ciò che rende la città provabile con `node --test` invece che a occhio, ed è la stessa separazione che ha salvato il banking (`TrackGeometry.rialzoBordi` deciso in un posto, letto da mesh, fisica e camera).

**Files:**
- Create: `frontend/shared/cittaProfilo.js` — modulo UMD nuovo
- Test: `frontend/shared/cittaProfilo.test.js`

**Interfaces:**
- Consumes: `TrackGravel.barrierAt(profile, i, side)`, `ToonPalette.SURFACES`
- Produces: `CittaProfilo.profilo(trackPts, barrierProfile, opzioni)` → `{ distanza: Float64Array(n×2), altezza: Float64Array(n×2), colore: Array(n×2) }`, indicizzati `[i*2 + (side>0?0:1)]`

```js
const test = require('node:test');
const assert = require('node:assert/strict');
const CittaProfilo = require('./cittaProfilo.js');
const TrackGeometry = require('./trackGeometry.js');
const TrackGravel = require('./trackGravel.js');

function ovaleConMuro() {
    const pts = [];
    for (let i = 0; i < 200; i++) {
        const a = (i / 200) * Math.PI * 2;
        pts.push({ x: Math.cos(a) * 300, z: Math.sin(a) * 300, y: 0, halfWidth: 11 });
    }
    const muro = TrackGravel.barrierProfile(pts, { roadHalf: 11, pitLanePts: [], pitRoadHalf: 5 });
    return { pts, muro };
}

test('la facciata comincia SUBITO oltre il muro, non a una distanza sua', () => {
    // «la vista è completamente occultata dai palazzi che circondano
    // perfettamente il circuito»: se cominciasse a distanza fissa, dove il muro
    // arretra per una via di fuga si aprirebbe un varco sul nulla.
    const { pts, muro } = ovaleConMuro();
    const p = CittaProfilo.profilo(pts, muro, {});
    for (let i = 0; i < pts.length; i++) {
        for (const side of [1, -1]) {
            const d = p.distanza[i * 2 + (side > 0 ? 0 : 1)];
            const m = TrackGravel.barrierAt(muro, i, side);
            assert.ok(d > m, `campione ${i} lato ${side}: facciata a ${d.toFixed(1)}, muro a ${m.toFixed(1)}`);
            assert.ok(d < m + CittaProfilo.MARCIAPIEDE + 0.01, `campione ${i}: facciata troppo lontana (${d.toFixed(1)})`);
        }
    }
});

test('i palazzi cambiano altezza a scalini, non di continuo', () => {
    // Un'altezza che varia campione per campione non si legge come una fila di
    // edifici: si legge come una duna. Serve che resti ferma per un bel pezzo e
    // poi salti.
    const { pts, muro } = ovaleConMuro();
    const p = CittaProfilo.profilo(pts, muro, {});
    let cambi = 0, uguali = 0;
    for (let i = 1; i < pts.length; i++) {
        if (p.altezza[i * 2] !== p.altezza[(i - 1) * 2]) cambi++; else uguali++;
    }
    assert.ok(cambi >= 3, `solo ${cambi} palazzi diversi su tutto il giro: sembra un muro unico`);
    assert.ok(uguali > cambi * 4, `l'altezza cambia troppo spesso (${cambi} volte): e' una duna, non una citta'`);
});

test('le altezze stanno nell\'intervallo dichiarato', () => {
    const { pts, muro } = ovaleConMuro();
    const p = CittaProfilo.profilo(pts, muro, {});
    for (const h of p.altezza) {
        assert.ok(h >= CittaProfilo.ALTEZZA_MIN && h <= CittaProfilo.ALTEZZA_MAX, `altezza ${h} fuori scala`);
    }
});

test('due piste uguali danno la stessa citta\', due diverse no', () => {
    // Deterministico: la stessa pista deve dare gli stessi palazzi ad ogni
    // caricamento, o il circuito cambierebbe faccia ad ogni partita. Il seme
    // viene dalla geometria, non da Math.random.
    const { pts, muro } = ovaleConMuro();
    const a = CittaProfilo.profilo(pts, muro, {});
    const b = CittaProfilo.profilo(pts, muro, {});
    assert.deepEqual(Array.from(a.altezza), Array.from(b.altezza));
    const spostata = { pts: pts.map(p => ({ ...p, x: p.x + 137 })), muro };
    const c = CittaProfilo.profilo(spostata.pts, muro, {});
    assert.notDeepEqual(Array.from(c.altezza), Array.from(a.altezza));
});

test('il colore di un palazzo non cambia in mezzo al palazzo', () => {
    const { pts, muro } = ovaleConMuro();
    const p = CittaProfilo.profilo(pts, muro, {});
    for (let i = 1; i < pts.length; i++) {
        const stessaAltezza = p.altezza[i * 2] === p.altezza[(i - 1) * 2];
        if (stessaAltezza) {
            assert.equal(p.colore[i * 2], p.colore[(i - 1) * 2],
                `campione ${i}: stesso palazzo, colore diverso`);
        }
    }
});
```
