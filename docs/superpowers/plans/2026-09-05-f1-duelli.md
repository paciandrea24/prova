# Duelli: difesa, traiettorie proprie, errori — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Quando il giocatore arriva dietro a un bot, il bot si sposta a coprirlo invece di lasciargli mezza pista libera; i sei bot smettono di essere sei copie sulla stessa linea; e ai livelli bassi sbagliano in modo credibile.

**Architecture:** Tutto lo scostamento laterale di un bot passa da **un solo punto**: oggi il ramo racing-line somma al target l'offset di sorpasso, e da lì passeranno anche la difesa e lo scostamento personale, che si combinano invece di sovrascriversi. Un modulo nuovo (`f1Duelli.js`) risponde a «di quanto devo spostarmi, e perché»; `f1Bot.js` gli chiede e applica. Gli errori sono un disturbo temporaneo su sterzo e frenata, acceso da un orologio interno al bot.

**Tech Stack:** Node.js, `node --test` + `node:assert/strict`; modulo UMD condiviso in `frontend/shared/`, come `f1Difficolta.js`.

**Spec:** `docs/superpowers/specs/2026-09-05-f1-duelli-design.md`

## Global Constraints

- **Italiano** nei commenti del codice e nei messaggi di commit.
- **Il difensore non rallenta**: la difesa cambia la traiettoria, mai `targetSpeed`. Un bot che frena per stare davanti è ciò che i giocatori riconoscono come «AI che bara».
- **Un solo cambio di traiettoria in difesa**, e **mai stringere chi è già affiancato**: sono le due regole vere della F1, e sono anche ciò che separa una difesa credibile da una fastidiosa.
- **Gli errori costano tempo, non la gara**: restano dentro i limiti della pista.
- **Non si toccano**: la racing line, il modello di guida (`cornerTargetSpeed`, pure-pursuit), il ritmo per livello e le soglie di aggressività del blocco H2, la regola che un bot non entra ai box nell'ultimo giro.
- **Le misure di riferimento** (`prova`, giro umano 47.30 s): la traiettoria sta a 5.42 unità da un lato su una mezza carreggiata di 11; lo spazio libero medio è 5.6 da una parte e 16.4 dall'altra; il 53% del giro ha più di 4 unità libere da entrambi i lati.
- **Baseline dei test, da rimisurare prima di cominciare**: `node --test backend/` → 931 test, **10 rossi + 2 skip**; `node --test frontend/shared/` → 1436 test, **5 rossi**. ⚠️ Il rosso `prova-notturno: i bot entrano davvero in corsia box` compare a intermittenza ed è un test casuale noto (verde 5 volte su 5 isolato): se appare, **non è una regressione** — si controlla l'elenco, non il conteggio.

```js
// frontend/shared/f1Duelli.js
//
// Di quanto un bot si sposta dalla sua linea, e perche'.
//
// ⚠️ NASCE DA UNA MISURA. Su `prova` la traiettoria dei bot sta a 5.42 unita'
// da un lato dell'asse, con una mezza carreggiata di 11: lascia 16.4 unita'
// libere dall'altra parte. L'utente, al playtest del 2026-09-05: «non c'e'
// duello perche' i bot sono costantemente all'interno quindi di lato in pista,
// io passo sempre dal lato opposto e li supero facilmente». Non e' un problema
// estetico: e' che il sorpasso e' regalato.
//
// Qui dentro NON si tocca la velocita'. Un bot che rallenta per restare
// davanti e' cio' che i giocatori riconoscono come «AI che bara»: la difesa
// sposta la traiettoria, non il piede.
(function (root, factory) {
    if (typeof module === 'object' && module.exports) module.exports = factory();
    else root.F1Duelli = factory();
})(typeof self !== 'undefined' ? self : this, function () {

    // ⚠️ UN SOLO CAMBIO DI TRAIETTORIA IN DIFESA, come impone il regolamento
    // vero. Fra un cambio e il successivo devono passare almeno due secondi:
    // senza, un bot inseguito da qualcuno che ondeggia si mette a ondeggiare
    // con lui, e si vede.
    const INTERVALLO_CAMBIO_MS = 2000;

    // Sotto questa distanza l'attaccante e' considerato affiancato: la porta
    // resta dov'e'.
    function scostamentoDifensivo(stato) {
        const s = stato || {};
        const attuale = s.scostamentoAttuale || 0;

        // Nessuno dietro, o troppo lontano: si torna sulla propria linea.
        if (!s.latoAttaccante || !(s.gapM < (s.finestraM || 30))) {
            return { scostamento: 0, motivo: 'lontano' };
        }
        // Affiancato: chiudergli la porta e' un contatto, non una difesa.
        if (s.affiancato) return { scostamento: attuale, motivo: 'affiancato' };

        // Gia' spostato da poco dall'altra parte: si resta dove si e'.
        const dallUltimo = (s.adessoMs || 0) - (s.ultimoCambioMs || 0);
        const cambierebbeLato = attuale !== 0 && Math.sign(attuale) !== Math.sign(s.latoAttaccante);
        if (cambierebbeLato && dallUltimo < INTERVALLO_CAMBIO_MS) {
            return { scostamento: attuale, motivo: 'gia-mosso' };
        }

        // Piu' e' vicino, piu' si copre: a meta' finestra si copre a meta'.
        const vicinanza = Math.max(0, Math.min(1, 1 - s.gapM / (s.finestraM || 30)));
        const forza = s.forza || 0;
        return { scostamento: Math.sign(s.latoAttaccante) * forza * vicinanza, motivo: 'copre' };
    }

    return { scostamentoDifensivo, INTERVALLO_CAMBIO_MS };
});
```

In `backend/sockets/games/f1Bot.js`, subito dopo `nearestAheadPlayer`:

```js
// Il simmetrico di nearestAheadPlayer: chi mi sta INSEGUENDO, quanto e' vicino
// e da che parte arriva.
//
// ⚠️ Serve anche il LATO, che a nearestAheadPlayer non serviva: una difesa
// senza sapere da dove arriva l'attacco copre a caso, e coprire il lato
// sbagliato e' peggio che non coprire — gli si apre la porta.
const BOT_AFFIANCATO_M = 8;   // lunghezza di un'auto piu' un margine
function nearestBehindPlayer(p, allPlayers, track) {
    const n = track.points.length;
    const metersPerSample = track.lapLength / n;
    let best = null, bestGap = Infinity;
    for (const q of allPlayers) {
        if (q === p || q.finished || q.pitting || q.pitAutoState) continue;
        // Distanza INDIETRO lungo il giro: quanto quello dietro deve ancora
        // percorrere per arrivare dove sono io.
        const delta = (((p.trackIndex || 0) - (q.trackIndex || 0)) % n + n) % n;
        const gapM = delta * metersPerSample;
        if (gapM < bestGap) { bestGap = gapM; best = q; }
    }
    if (!best) return null;
    // Da che lato dell'asse sta, nel MIO punto di pista: e' li' che dovro'
    // spostarmi, non dove sta lui adesso.
    const idx = p.trackIndex || 0;
    const centro = track.points[idx];
    const nrm = TrackGeometry.normalAt(track.points, idx, true);
    const lato = Math.sign((best.x - centro.x) * nrm.nx + (best.z - centro.z) * nrm.nz) || 1;
    return { player: best, gapM: bestGap, lato, affiancato: bestGap < BOT_AFFIANCATO_M };
}
```

Aggiungerla all'export accanto a `nearestAheadPlayer`.

- [ ] **Step 3: L'orologio dell'errore**

In `f1Bot.js`:

```js
// Un errore dura poco e costa qualche decimo: il bot allarga in uscita o
// frena troppo tardi, non finisce in ghiaia.
//
// ⚠️ COSTA TEMPO, NON LA GARA (spec 2026-09-05). Un bot che sbaglia deve
// restare dentro i limiti della pista: e' la differenza fra un avversario
// divertente e uno rotto.
const BOT_ERRORE_DURATA_MS = 900;
const BOT_ERRORE_STERZO = 0.25;    // quanto allarga, in frazione di sterzo
const BOT_ERRORE_FRENO = 0.15;     // quanto ritarda la frenata

// Decide se comincia un errore, e lo fa scadere. Restituisce true nel tick in
// cui un errore COMINCIA — cosi' si puo' contare senza guardare dentro.
function aggiornaErrore(p, erroriPerGiro, tickMs, giroMs) {
    if (p.botErroreFinoMs && p.botErroreFinoMs > (p.botOrologioMs || 0)) {
        p.botOrologioMs = (p.botOrologioMs || 0) + tickMs;
        return false;
    }
    p.botOrologioMs = (p.botOrologioMs || 0) + tickMs;
    // Probabilita' per tick che porta a `erroriPerGiro` errori in un giro.
    const perTick = (erroriPerGiro || 0) * tickMs / (giroMs || 50000);
    if (Math.random() >= perTick) return false;
    p.botErroreFinoMs = (p.botOrologioMs || 0) + BOT_ERRORE_DURATA_MS;
    // Metà delle volte allarga, metà frena tardi.
    p.botErroreTipo = Math.random() < 0.5 ? 'allarga' : 'frenata';
    return true;
}
```

E dove si compongono gli input, dopo che sterzo e freno sono stati decisi:

```js
            // L'errore in corso: allarga l'uscita o ritarda la frenata.
            if (p.botErroreFinoMs > (p.botOrologioMs || 0)) {
                if (p.botErroreTipo === 'allarga') steer *= 1 - BOT_ERRORE_STERZO;
                else brake *= 1 - BOT_ERRORE_FRENO;
            }
```

⚠️ **Non in qualifica**: un giro secco rovinato da un errore casuale falsa la griglia, e la griglia decide la gara. Chiamare `aggiornaErrore` solo con `game.phase === 'race'`.
