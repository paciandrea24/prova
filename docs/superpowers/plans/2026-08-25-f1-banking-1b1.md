# Il banking si vede e si sente (fase 1b-1) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Un tratto puo' essere sopraelevato: il nastro si inclina, l'auto e la camera con lui, la tenuta in curva aumenta, e il terreno sotto regge il fianco alto.

**Architecture:** `rollio` (radianti) segue la strada gia' battuta da quota e larghezza: campo per TRATTO nell'editor → cotto sul PUNTO da `TrackSegmenti.cuoci` → garantito su ogni campione da `trackLoader`. Il verso non e' nel dato: si alza sempre il lato esterno della curva, deciso dal segno di `curvatureAt().turnSigned`. La mesh alza il vertice esterno di `sin(rollio) * 2 * mezzaCarreggiata`; la fisica moltiplica `corneringCapacity`, che il bot gia' consulta.

**Tech Stack:** Node.js, `node --test` + `node:assert/strict`, moduli UMD condivisi (`frontend/shared/*.js`), Three.js r128 lato client.

**Spec:** `docs/superpowers/specs/2026-08-25-f1-nastro-orientato-design.md` (fase 1b, decisioni D1, D2, D6)

- [ ] **Step 3: Implementare**

```js
    // Di quanto si alza il bordo alto di un tratto sopraelevato, e QUALE bordo
    // e'. È l'unico posto dove il verso della sopraelevazione viene deciso:
    // mesh, cordoli, terrapieno, fisica ed editor lo chiedono qui invece di
    // ricavarselo, o un giorno l'asfalto si alzerebbe da una parte e il cordolo
    // dall'altra (Rif. decisione D6 della spec).
    //
    // Si alza sempre l'ESTERNO della curva: il bordo interno resta alla quota
    // che ha, e il nastro si appoggia sul terreno esistente senza bucarlo.
    // Su un tratto dritto non esiste un esterno: li' il rollio non ha effetto
    // (e il validatore lo segnala, invece di lasciare una sopraelevazione
    // invisibile).
    //
    // `dyAlto` e' l'alzata TOTALE del bordo alto rispetto a quello basso:
    // sin(rollio) * larghezza intera, cioe' 2 * mezza.
    const RETTILINEO_R_MIN = 400;   // oltre questo raggio il tratto e' dritto
    function rialzoBordi(points, i, mezza) {
        const rollio = points[i] && points[i].rollio ? points[i].rollio : 0;
        if (!(rollio > 0)) return { dxAlto: 0, dyAlto: 0, latoAlto: 0 };
        const { radius, turnSigned } = curvatureAt(points, i);
        if (!(radius < RETTILINEO_R_MIN) || turnSigned === 0) {
            return { dxAlto: 0, dyAlto: 0, latoAlto: 0 };
        }
        // Il lato esterno e' quello opposto al verso di curvatura.
        const latoAlto = turnSigned > 0 ? -1 : 1;
        return { dxAlto: 0, dyAlto: Math.sin(rollio) * 2 * mezza, latoAlto };
    }
```
